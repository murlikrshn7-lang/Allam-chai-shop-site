# ☕ Allam Chai Shop — Digital Storefront & Ordering Platform

> Transforming a local neighborhood chai spot with zero web presence into a fully functioning digital store with Google Search visibility, WhatsApp ordering, and online payments.

---

## 🌟 Business Impact & Transformation

Prior to this project, Allam Chai Shop operated strictly offline. This repository powers their end-to-end digital door:

1. **Google Business & Online Visibility:** Established local search indexing so nearby customers can discover the store.
2. **Digital Menu & Web Storefront:** Clean menu interface featuring 23 catalog items across Tea, Beverages, and Dairy.
3. **Seamless WhatsApp Ordering:** Direct-to-WhatsApp checkout workflow allowing customers to order without needing complex account registration.
4. **Digital Payments:** Integrated payment acceptance for quick local transactions.

---

## 🛍️ Product Catalog Overview

The store manages 23 daily items categorized across:
* **☕ Hot Teas & Brews:** Special Fresh Allam Chai (Customizable by headcount)
* **🥤 Cold Beverages:** Soft drinks, juices, energy drinks, and bottled water (Kinley, Bisleri, Thums Up, Sprite, Maaza, Badam Milk)
* **🥛 Fresh Dairy:** Daily essentials (Heritage Curd, Salted Butter, Fresh Paneer)

---

## 🛠️ Tech Stack & Architecture

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Data Source:** Dynamic product mapping with fallback data handling
- **Ordering Engine:** Direct WhatsApp API Deep Linking (`https://wa.me/...`)
- **Hosting:** GitHub Pages / Web Hosting
